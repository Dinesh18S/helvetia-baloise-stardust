# Project

Unaffiliated concept redesign of the Helvetia Baloise Swiss private customer
page, for an Adobe take home exercise. Not a real client engagement.

## Hard rules

* Never invent brand assets, logos, colours or typefaces. If a value is not
  sourced from the live site or the published merged identity, ask me.
* Design in German first. French is the layout stress test.
* No text content that makes factual claims about products, prices or cover.
  Reuse the live page's own copy or clearly generic placeholder.
* Accessibility floor: every interactive element gets an accessible name,
  the document gets a main landmark.
